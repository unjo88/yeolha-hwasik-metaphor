# 한·중 고전문헌 재화 인식 재맥락화 — 연구 자료

논문 「한·중 고전문헌에 나타난 재화 인식의 언어문화적 재맥락화 고찰: *열하일기*와 *사기*의 재화 관련 은유를 중심으로」(『문화와 융합』 게재 예정)의 판정 자료와 산출 자료, 재현 코드를 공개하는 저장소입니다.

논문 지면에는 감각성 지수 산출에 필요한 어휘 목록과 텍스트별 산출 원표만 실었습니다. 나머지 자료는 모두 이곳에서 확인할 수 있습니다.

## 재현 실행 환경

어휘 목록을 고쳐 넣으면서 감각성 지수가 어떻게 달라지는지 확인할 수 있는 도구를 Streamlit Community Cloud에 올려 두었습니다.

**【배포 후 주소 기재】**

로컬에서 실행하려면 다음과 같이 합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

명령줄에서 산출 결과만 보려면 다음과 같이 합니다.

```bash
python concreteness.py
```

## 재현 결과

논문 부록에 제시한 트리거 단어 41개와 A 목록 64자, B 목록 42자, 그리고 문맥 추출 절차만을 조건으로 삼아 원문 코퍼스에서 감각성 지수를 다시 산출한 결과입니다.

| 텍스트 | 문맥 추출수 | A | B | 재현 지수(%) | 논문 게재치(%) |
|---|---:|---:|---:|---:|---:|
| 화식열전 | 119 | 71 | 81 | 46.7 | 46.7 |
| 도강록 | 92 | 61 | 46 | 57.0 | 56.9 |
| 관내정사 | 75 | 41 | 50 | 45.1 | 45.1 |
| 옥갑야화 | 60 | 57 | 29 | 66.3 | 66.3 |
| 행재잡록 | 18 | 12 | 5 | 70.6 | 70.6 |
| 성경잡지 | 82 | 35 | 38 | 47.9 | 47.9 |
| 일신수필 | 80 | 67 | 43 | 60.9 | 60.9 |
| 열하일기 6편 합계 | 407 | 273 | 211 | 56.4 | 56.4 |

여섯 텍스트에서 문맥 추출수와 A·B 빈도가 게재치와 완전히 일치합니다. 「도강록」만 문맥 92건(게재치 94건), A 61(62), B 46(47)으로 어긋나 지수가 0.1%포인트 차이를 보이는데, 인접 문맥의 병합 경계를 처리하는 방식의 미세한 차이에서 비롯된 것으로 보입니다.

「심세편」은 추출 문맥이 7건(A=0, B=5)에 그쳐 정량 비교에서 제외하였습니다. 자료는 투명성을 위해 함께 수록합니다.


## 은유 판정 자료

`research_data.xlsx`의 `은유판정_122건` 시트에 「관내정사」·「행재잡록」·「심세편」·「옥갑야화」 105단락과 「성경잡지」·「일신수필」 구 단위 17건, 합계 122건의 판정 내역이 들어 있습니다. 텍스트, 단위코드, 원문 요약, 세부 은유 유형, 7대 대분류 코드와 명칭을 담고 있으며, 여기서 식별된 세부 은유 유형은 119종입니다.

매핑 규칙을 확정한 「화식열전」 50단락과 「도강록」 60단락의 건별 판정 내역은 아직 이 저장소에 포함되어 있지 않습니다.

## 산출 절차

**열하일기** 원문을 공백 단위 어구로 분절한 뒤, 트리거 단어가 포함된 어구와 그 앞뒤 각 1개 어구를 묶어 재화 관련 문맥으로 삼습니다. 인접하거나 겹치는 구간은 병합합니다.

**화식열전** 표점본을 「。」 단위로 분절한 뒤, 트리거 단어가 포함된 문장을 문맥으로 삼습니다.

**지수** 감각성 지수(%) = A ÷ (A + B) × 100

A·B 판정은 문맥별 개별 판정이 아니라 사전에 확정한 어휘 목록에 따라 일괄 적용합니다. 빈도는 표제어가 아니라 글자 단위 출현형을 기준으로 세며, 같은 글자가 반복되면 각 출현을 개별적으로 계산합니다. A·B 어느 목록에도 없는 글자는 산출에서 제외합니다.

## 자료 이용

원문 자료는 한문 원문과 서지 좌표(권·편·문단번호)까지만 공개하며, 번역문은 인용 범위로 한정합니다. 저본은 한국고전번역원 한국고전종합DB(『연암집』)와 中華書局本 『사기』입니다.
