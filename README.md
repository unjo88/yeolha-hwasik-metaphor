# 열하일기·화식열전 재화 은유 판정 자료

한·중 고전문헌에 나타난 재화 인식의 언어문화적 재맥락화 연구의 판정 자료와 재현 코드입니다.

## 이 저장소의 상태

**2026년 8월 현재 재코딩이 진행 중입니다.** 초기 제출본의 건별 판정 자료 가운데
「화식열전」·「도강록」 110건분이 확보되지 않아, 분석 단위를 절(節)로 다시 정의하고
전면 재코딩과 코더 간 교차검증을 수행하고 있습니다.

`v1` 태그에 초기 제출본 기준 자료가 보존되어 있습니다.

## 분석 설계

**분석 단위는 절입니다.** 두 저본이 각자의 방식으로 표시한 경계를 그대로 씁니다.
「화식열전」은 표점본의 표점(，。：；)으로, 열하일기는 저본의 띄어쓰기로 나눕니다.
연구자가 임의로 정한 분절이 아닙니다.

두 저본의 절 길이는 사실상 같습니다. 「화식열전」 1,155절 평균 4.14자(중위 4.0),
열하일기 16,278절 평균 4.98자(중위 4.0)입니다.

**판정 대상**은 트리거 41개를 포함한 절과 그 앞뒤 각 1절이며, 두 문헌에 같은 규칙을
적용합니다. 8편 합계 1,880절입니다.

| 텍스트 | 전체 절 | 판정 대상 |
|---|---|---|
| 화식열전 | 1,155 | 394 |
| 도강록 | 4,253 | 324 |
| 성경잡지 | 3,338 | 295 |
| 일신수필 | 3,270 | 273 |
| 관내정사 | 3,523 | 254 |
| 옥갑야화 | 891 | 254 |
| 행재잡록 | 640 | 65 |
| 심세편 | 363 | 21 |
| 합계 | 17,433 | 1,880 |

**분류 축은 원천 영역 하나로 통일했습니다.** 과장·역설·대조는 두 영역 사이의 사상이
아니라 표현을 조직하는 수사 기제이므로 구성비 산출에서 분리하여 보조 지표로 제시합니다.
아울러 모든 은유 항목에 목표 영역 코드를 붙여 원천 × 목표 교차표를 산출합니다.

## 구성

```
docs/     은유판정_지침서.docx        판정 절차·주의사항·Kappa 산출법
data/     원문 코퍼스 4종             분석 저본과 대조 코퍼스
          clauses.csv                 절 분절 결과 17,433행
code/     segment_clauses.py          절 분절과 판정 대상 추출
          shared_ngram.py             저빈도 공유 표현 검색과 대조 검증
coding/   은유판정지_원본_빈양식.xlsx   판정지 원본
          은유판정지_판정자1·2_배포본   실제 배포한 판정지
results/  Kappa_산출기_빈양식.xlsx     일치도 산출 서식
```

## 재현 방법

```bash
pip install pandas openpyxl
python code/segment_clauses.py --data ./data --out clauses.csv
python code/shared_ngram.py    --data ./data --out shared.csv
```

`clauses.csv`가 `data/clauses.csv`와 일치하면 절 분절이 재현된 것입니다.

## 저본

- 열하일기: 한국고전번역원 한국고전종합DB, 연암집 권11~15
- 화식열전: 中國哲學書電子化計劃 표점 전자본
- 대조 코퍼스: 무경칠서(53,911자), 사서집주(193,317자)

인쇄 판본과의 대조는 김혈조 역 정본(2025)과 王利器 주편 史記注譯(1988)으로
총 29개 문단에 대해 수행하였으며 표기가 어긋나는 곳은 확인되지 않았습니다.

## 판정 절차

두 판정자가 서로의 판정과 연구자의 초고를 보지 않은 상태에서 독립적으로 판정한 뒤,
Cohen's Kappa를 은유 여부·원천 영역·목표 영역 세 층위에서 산출합니다.
연구자 본인은 판정에 참여하지 않고 불일치 항목의 조정만 맡습니다.
불일치 처리 절차는 판정 개시 전에 확정하였습니다(`docs/판정기준_합의문.pdf`).

판정지에는 주요 글자의 기본 의미와 직역·의역이 참고 자료로 붙어 있습니다.
이 번역은 대규모 언어모델(Claude)이 작성한 초벌이며, 판정자에게 원문 우선 원칙을
명시하여 제공하였습니다.
